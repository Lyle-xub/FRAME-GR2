## WN9 测试版软件

以下为 **FRAME App 1.0.3（103）** 的功能与测试入口，部分新增功能需要 WN9 测试固件。

FRAME 用于管理 RICOH GR II 的滤镜、素材与照片。手机与电脑采用统一的功能分组，处理和拟合在本机完成。

| 功能 | 可以完成的操作 |
| :-- | :-- |
| 滤镜库 | 导入 CUBE、兼容 XMP 与项目 JSON，编辑名称、胶片图标、配色和 Emoji，管理机内滤镜位置。 |
| 拟合与预览 | 选择 WN3 拟合或 V5 联合拟合，对比原图、LUT 与拟合结果；V5 支持暂停、继续和任务恢复。 |
| 参考照片 | 切换多场景样图，也可使用自己的照片预览；内置 CINESTILL 800T。 |
| 照片装饰 | 准备、预览并导入三槽自定水印，调整 GR 标识与装饰素材。 |
| 关机素材 | 导入图片、GIF 和视频，缩放、旋转并调整构图。 |
| 音效编辑 | 导入音频、波形裁切、微调与试听，设置关机音效、对焦确认音和快门提示音，并调整音量。 |
| 参数调整 | 从 Fn2 进入「无」、原生、负片或自定滤镜的支持参数页，分别选择滤镜强度和光效档位。 |
| 原图导出 | 浏览相机照片，筛选 JPEG / RAW，单张或批量导出，保留原始文件内容。 |
| SD 卡管理与更新 | 浏览、上传和下载文件，支持中文等文件名；读取固件版本并校验更新文件。 |

**支持平台：Android、macOS（Apple Silicon）、Windows x64、iPhone / iPad。**

iPhone / iPad 的 **1.0.3（103）已开放内部测试，并已提交 Apple 外部 Beta 审核**。
