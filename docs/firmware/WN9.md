# FRAME · WN9 固件

**适用机型：RICOH GR II。** WN9 在相机原有菜单和拍摄流程中提供更多色彩、光效、画幅和照片信息选择。

### 色彩与光效

- 负片与个人滤镜拥有独立参数调整；自定滤镜可切换原生拟合与 LUT17 成片模式。
- 提供 HDF、胶片颗粒、高光溢出和横向拉丝；两项光效在颜色处理完成后叠加。
- 配套 App 可导入个人 CUBE / XMP，并选择 WN3 拟合或 V5 联合拟合。

### 构图与照片装饰

- 支持 XPan、自定义照片比例与独立 RAW 比例设置。
- 支持三槽自定水印、四向 GR 标识与机内照片装饰。
- 回放按 DISP，可在原生信息面板查看拍摄时的滤镜、图标和参数，支持 JPEG、RAW、RAW+。
- RAW 编辑可选择负片和自定滤镜，并调整 HDF、颗粒及两项光效参数。

### 连接与更新

- App 可读取固件名称，显示 WN9 并确认更新状态。
- 提供 SD 文件管理与固件上传接口，支持中文等 Unicode 文件名和长文件名。
